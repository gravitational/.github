## Teleport

Welcome to the @gravitational GitHub Org, home of [Teleport](https://goteleport.com/), the AI Infrastructure Identity Company.

The [Teleport Infrastructure Identity Platform](https://goteleport.com/platform/) establishes a unified identity layer for infrastructure. Humans, machines, workloads and AI agents all get identities that are secured cryptographically instead of relying on static credentials. By replacing fragmented identity and access management systems with Infrastructure Identity, Teleport scales zero trust across cloud and on-prem environments. Teleport:

- **Protects infrastructure from identity attacks** by eliminating credential sprawl and long-lived secrets.
- **Modernizes privileged access and accelerates engineering** with just-in-time, short-lived access, and fewer tools to run.
- **Secures agentic AI and MCP**, so teams can ship AI initiatives without taking on identity risk.

## Teleport Beams
[Teleport Beams](https://beams.run), the trusted runtime for AI agents, is now generally available. Beams runs each agent in an ephemeral, isolated micro-VM with its own X.509 identity, tied to access delegated from a human, and the agent never holds the private key. Agents connect to cloud, database and Kubernetes resources without secrets, with least-privilege access, just-in-time elevation and tool-level RBAC for MCP servers. Every model call and infrastructure action is captured for audit, and Phases let you snapshot, fork and branch an agent's running state.

## History of @gravitational GitHub Org
Teleport started its life as Gravitational. What we built at Gravitational was Gravity and Teleport. The Gravity project was meant to be the “runtime” for applications, while the goal of Teleport was to provide an easy way to access it. In November of 2020, [Gravitational re-branded as Teleport](https://goteleport.com/blog/gravitational-is-teleport/), and since then we've continued to execute Teleport's mission to enable engineers to quickly access any resource anywhere.
